# 🏥 Tech.Care - Patient Dashboard

A modern, responsive patient dashboard built with **React**, **Chart.js**, and **REST API integration**. This project showcases dynamic medical data visualization including vitals, diagnostics, and lab results for healthcare professionals.

## ✨ Features

- 👨‍⚕️ Patient selection panel with avatars
- 📊 Interactive blood pressure chart (monthly range selector)
- 💓 Vital signs with icons and emoji indicators
- 🧾 Scrollable diagnostic history
- 🧪 Lab results with download icons
- 📋 Profile sidebar for personal and insurance info
- 🔄 Real-time data from a secure API (Basic Auth protected)
- 🎨 Clean, responsive UI styled with CSS Grid/Flexbox

---

## 🛠 Tech Stack

- **React.js** – UI library
- **Chart.js** – Graphing blood pressure data
- **Axios** – API communication
- **CSS3** – Custom responsive layout & styling

---

## 🚀 Getting Started

### Prerequisites

- Node.js v14+ and npm installed

### Installation

```bash
git clone https://github.com/akulasai07/patient-dashboard.git
cd  patient-dashboard
npm install 
```

##Running the App

```bash

npm start

```

-This will launch the app on http://localhost:3000
